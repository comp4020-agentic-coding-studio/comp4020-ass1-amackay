# Fonts

Shipped, not linked: the statements have to be set in the same face for every
reader, and a system font stack cannot promise that.

- `KaTeX_Main-Regular.woff2` — brackets, operators, `⊢`, upright Latin.
- `KaTeX_Math-Italic.woff2` — Greek and italic Latin, the variables.

Both from [KaTeX](https://github.com/KaTeX/KaTeX) v0.16.11, `dist/fonts/`, MIT.
Already subsetted per style by that project, so nothing here subsets them.
